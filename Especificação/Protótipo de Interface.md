# Protótipo de Interface (Wireframe) - Gerador de Senhas

## Objetivo
Este protótipo tem como finalidade representar visualmente a interface do gerador de senhas, permitindo antecipar a experiência do usuário antes da implementação final.

## Estrutura da Interface

```text
┌─────────────────────────────────────────────────────────────────────┐
│                     GERADOR DE SENHAS                             │
├─────────────────────────────────────────────────────────────────────┤
│  Crie uma senha forte e segura                                     │
│                                                                     │
│  ┌───────────────────────────────────────────────────────────────┐   │
│  │ Senha gerada: 7Kp!mQ9@Lx2#Tz8                              │   │
│  └───────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  Comprimento da senha: [ 16 ]   [ + ] [ - ]                       │
│                                                                     │
│  [x] Maiúsculas    [x] Minúsculas    [x] Números    [x] Símbolos   │
│                                                                     │
│  [ Gerar Senha ]    [ Copiar ]                                     │
│                                                                     │
│  Força da senha:  ██████ Forte                                     │
│                                                                     │
│  [ Gerar outra senha ]                                             │
└─────────────────────────────────────────────────────────────────────┘
```

## Elementos principais
- Título principal: “Gerador de Senhas”
- Campo central exibindo a senha gerada
- Controle de comprimento da senha
- Opções de caracteres: maiúsculas, minúsculas, números e símbolos
- Botões de ação: gerar senha e copiar
- Indicador visual de força da senha

## Fluxo sugerido de uso
1. O usuário define o comprimento desejado.
2. Seleciona os tipos de caracteres que deseja incluir.
3. Clica em “Gerar Senha”.
4. A senha aparece no campo principal.
5. O usuário pode copiar a senha ou gerar outra opção.

## Observações
- A interface deve ser simples, limpa e intuitiva.
- O foco principal deve estar na rapidez de uso e na clareza das opções.
- A experiência deve ser responsiva, funcionando bem em desktop e dispositivos móveis.
